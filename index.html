Para que serve esta lista?

Ela existe para você se organizar e mostrar no caixa o que deseja. Monte o pedido com calma enquanto anda pela festa e, na hora de pagar, é só mostrar esta tela: o atendimento fica mais rápido e a fila anda melhor para todo mundo.

A lista fica salva só no seu celular. Nada é enviado para a barraca e nenhum item fica reservado — o pedido é feito e pago no caixa, normalmente.
